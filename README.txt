Grade 5 Health — Alberta PEW
============================

36 weekly 30-minute wellness lessons a substitute can teach from the page.
Six units, printable worksheets, family letter, progress stamps.

This folder is a complete website. There is no login and no database.
Student/teacher progress is saved in the browser on that device.

How to put it online
--------------------
Upload the contents of this folder (not a parent wrapper) to any static host,
at the site root:

  • Netlify or Cloudflare Pages: drag the unzipped folder onto the dashboard
  • GitHub Pages: put these files at the root of the Pages branch
  • School / district web server: copy the folder to the web root

Open the site in a browser. Start at the home page, then Week 1.

Do not double-click index.html. It needs to be served as a website
(paths such as /week/12 only work from a real web host).
